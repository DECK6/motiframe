# 작은 신호, 다른 재료

Three scenes combine React typography, custom HTML circles and grids, original video and a sparse generated soundtrack.

640 × 360 · 30 fps · 30 seconds · 900 frames.

Generated by `bunx tsx scripts/create-showcase.ts`. All timing is deterministic. The video and soundtrack are original synthetic material. Noto Sans KR is included under SIL OFL 1.1; see assets/OFL.txt.

This folder is a portable working project with relative asset paths and bundled custom HTML source/artifacts.
