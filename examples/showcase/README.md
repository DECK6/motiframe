# MotiFrame motion studies

Three authored examples distinguish speed, tension and rhythm.

- [사이의 리듬](hangul/project.json): 15 seconds of Hangul typography with long reading windows.
- [해소를 미룬 시간](slow-tension/project.json): a 10-second intentional unresolved tension.
- [작은 신호, 다른 재료](mixed/project.json): a 30-second React / HTML / video composition in three scenes.

Regenerate with `bunx tsx scripts/create-showcase.ts`. Each working folder is portable.
